Lavender Clock — исходный проект Android-приложения и облачная сборка APK.

Дизайн: тёмный фон, крупные тонкие вытянутые часы светло-сиреневого цвета.
Приложение открывается как отдельный полноэкранный экран часов.

КАК ПОЛУЧИТЬ APK ЧЕРЕЗ GITHUB ACTIONS:
1. Создайте бесплатный аккаунт на github.com и новый пустой репозиторий.
2. Загрузите в репозиторий ВСЕ файлы и папки из этого архива (включая скрытую папку .github).
3. Откройте вкладку Actions в репозитории.
4. Выберите "Build Lavender Clock APK" и нажмите "Run workflow".
5. Дождитесь зелёного статуса сборки.
6. Откройте завершённый запуск и скачайте артефакт "LavenderClock-debug".
7. Распакуйте скачанный архив — внутри будет app-debug.apk. Откройте APK на OPPO и разрешите установку из этого источника.

ВАЖНО:
Это отдельное полноэкранное приложение часов, НЕ системный шрифт ColorOS и НЕ замена защищённому экрану блокировки OPPO.
Оставьте системный PIN-код/отпечаток включённым.
